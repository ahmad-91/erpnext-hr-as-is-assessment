# تقييم الوضع الحالي (As-Is) — ERPNext الموارد البشرية

تطبيق ويب تفاعلي لتقييم الدورات الحالية في الموارد البشرية قبل تطبيق **ERPNext**، عبر بطاقات أسئلة لمديري الإدارات والمشرفين وأخصائيي HR والموظفين.

## المنهجية

يعتمد التقييم على أبعاد نضج العمليات العالمية:

| البعد | ماذا يقيس |
|--------|-----------|
| الأشخاص | وضوح الأدوار والصلاحيات |
| الإجراءات | التوثيق وزمن الدورة |
| التقنية | الأدوات والأنظمة الحالية |
| البيانات | الجودة والمصدر الواحد |
| الضوابط | الموافقات والامتثال (قوى / حماية الأجور) |
| نقاط الألم | الاختناقات وإعادة العمل |

كل دورة تحصل على درجة نضج من **١ إلى ٥** (أولي → محسَّن).

## الدورات المشمولة (المرحلة الحالية)

1. التوظيف والتعيين  
2. إدارة عقود الموظفين  
3. الحضور والانصراف  
4. الإجازات والمغادرات  
5. مسير الرواتب  
8. إدارة الموظفين  
9. التقييم والتدريب  
10. إنهاء الخدمة  

## التشغيل محلياً

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## النشر على Vercel

1. اربط المستودع بمشروع Vercel جديد.
2. Framework Preset: **Next.js** (افتراضي).
3. Build Command: `npm run build`
4. بعد النشر، شارك رابط الموقع مع المشاركين في التقييم.

أو عبر CLI:

```bash
npx vercel
```

## استخدام النتائج

- تُحفظ الإجابات محلياً في متصفح المشارك.
- يمكن **تصدير JSON** لكل مشارك ثم تجميعها في ورشة توحيد As-Is.
- الدورات ذات النضج الأقل تُعطى أولوية في تصميم To-Be وتكوين ERPNext.
