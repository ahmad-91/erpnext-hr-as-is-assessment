# تقييم الوضع الحالي (As-Is) — ERPNext

تطبيق ويب تفاعلي لتقييم الدورات الحالية قبل تطبيق **ERPNext**، مع حفظ الإجابات في قاعدة بيانات ولوحة أدمن لتجميع النتائج.

## المرحلة الحالية: الموارد البشرية

1. التوظيف والتعيين  
2. إدارة عقود الموظفين  
3. الحضور والانصراف  
4. الإجازات والمغادرات  
5. مسير الرواتب  
8. إدارة الموظفين  
9. التقييم والتدريب  
10. إنهاء الخدمة  

الهيكل جاهز لإضافة وحدات أخرى لاحقاً (مالية، مشتريات، مخزون…) عبر `moduleId`.

## ماذا يعني SOP؟

**SOP** = *Standard Operating Procedure* = **إجراءات العمل القياسية**: وثيقة مكتوبة تشرح خطوة بخطوة كيف تُنفَّذ العملية (من يبدأها، من يعتمدها، وما النماذج المطلوبة). يظهر شرحها داخل صفحة التقييم عند سؤال التوثيق.

## التشغيل محلياً

```bash
npm install
npx prisma db push
npm run dev
```

- التقييم: [http://localhost:3000](http://localhost:3000)
- لوحة الأدمن: [http://localhost:3000/admin](http://localhost:3000/admin)

كلمة مرور الأدمن الافتراضية (من `.env`):

```
ADMIN_PASSWORD=erpnext-admin
```

## المتغيرات البيئية

انسخ `.env.example` إلى `.env`:

```
DATABASE_URL="file:./dev.db"
ADMIN_PASSWORD="erpnext-admin"
```

> للإنتاج على Vercel استخدم Postgres (مثل Neon) وغيّر `provider` في `prisma/schema.prisma` إلى `postgresql` مع `DATABASE_URL` الخاص بقاعدة السحابة.

## لوحة الأدمن

- عدد المشاركين ومتوسط النضج العام
- متوسط النضج لكل دورة
- أكثر **المشاكل الحالية** تكراراً
- سجل المشاركات مع تفاصيل كل مشارك
